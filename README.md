# Vault — Book & Film Tracker

A personal archive of everything you've read and watched.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- React 18
- Vite
- CSS Modules
- localStorage (data stored in the browser)

## Features

- Add books and films to your collection
- Track status: want / in progress / finished
- Rate entries on a 5-star scale
- Add personal notes to each entry
- Search, filter by type and status, sort by various fields
- Collection statistics
- Data persists via localStorage
